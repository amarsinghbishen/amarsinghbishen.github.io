# Amar Bahadur Singh — GitHub Pages Portfolio

Personal portfolio website for Amar Bahadur Singh.

## Live site
https://amarsinghbishen.github.io/

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages

## Deployment
Push the contents of this repository to the `main` branch and enable GitHub Pages from:
Repository → Settings → Pages → Deploy from a branch → `main` / `/ (root)`.
